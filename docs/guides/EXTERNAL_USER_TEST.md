# HolderProof 独立用户试用

这份任务单用于执行方案 06 的可用性评测，以及排期中的团队外用户测试。
目标是至少三位团队外参与者各自完成一次查询和资格判断。请先记录
操作系统、工具是否已安装及开始时间。用匿名编号记录反馈即可。

1. 从仓库 README 开始，按[测试操作指引](TESTING.md)的环境检查和手动测试步骤启动 demo。
2. 用 README 的查询命令获取示例 holder 在区块 1000 的证书，记录余额、证书状态和签名者数量。
3. 查看 README 列出的空投和治理结果，记录各自门槛、资格结果，以及两个结果中的 `queryHash` 是否一致。
4. 记录总耗时和遇到的问题。如果未完成，记录卡在哪一步以及可分享的错误信息。按 README 停止 demo。
