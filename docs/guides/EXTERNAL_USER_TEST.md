# HolderProof 独立用户试用

方案 06 的目标是让至少三位团队外参与者各自完成一次余额查询和资格核对。
团队为每位参与者分配一个匿名编号，如 `E01`。

## 开始试用

克隆仓库后，从仓库根目录运行以下命令，把 `E01` 换成你的编号。
依赖和本地端口要求见[测试操作指引](TESTING.md)。

```bash
python3 scripts/record_external_test.py E01
```

1. 脚本先检查环境。按终端提示依次确认启动 demo、查询 Alice 在区块 1000 的余额。
2. 打开终端给出的两个本地地址，查看空投和治理的 `threshold`、`eligible`。核对后回到终端继续。
3. 选择是否获得了协助。可以留下一行反馈，说明卡点、所获帮助或建议。

遇到报错时，脚本会在表单中标记未完成步骤。你也可以在步骤提示处输入 `q` 结束试用。
如需安装依赖，请按测试指引操作。安装前后的两次记录会保存在不同目录。

## 交回结果

把终端显示路径下的 `feedback.md` 发给团队。提交号、系统、从环境检查开始的试用耗时、
余额、签名人数和两个 Gate 的结果均由脚本填写。报错时也可以交回表单，并按需附上该步骤的日志。
证书和日志随表单保存在本机 `.run/external-tests/` 下。

如果本轮启动了 demo，交回证据后运行 `make stop-demo`。团队根据表单区分独立完成、
协助后完成和未完成。参与者可用反馈栏注明尝试前的依赖安装用时。
